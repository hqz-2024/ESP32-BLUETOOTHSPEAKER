# 推荐眼睛动画

- 休息时: 闭眼状态
- 唤醒时: 眨眼一次
- 说话时: 眨眼并且时不时左右移动眼珠子
- 快乐时: 出现下眼皮并且眨眼
- 伤心时: 出现下眼皮和上眼皮
